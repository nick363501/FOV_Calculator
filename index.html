How this works: typing any Messier / NGC / IC designation looks it up live via the CDS Sesame name resolver, so it works for the full catalog — the dropdowns above are just shortcuts for common targets. Sky imagery is real astronomical survey data (DSS), so this needs an internet connection each time it's used, same as Telescopius/Stellarium's online mode. "Tonight's Best" ranks from a bundled catalog of ~2,500 galaxies, clusters, and nebulae (OpenNGC), not just the dropdown shortcuts.

This is a self-contained web page (no installer, no backend). To use it later on your iPhone/iPad, just put this whole project folder on any static web host (e.g. a free GitHub Pages or Netlify site) and open that URL in Safari — no changes needed.
